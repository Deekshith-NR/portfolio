# Deekshith N R — Portfolio Website

## Run locally
1. Extract the ZIP (if using the ZIP).
2. Open `index.html` in Chrome, Edge, or Firefox.
3. To publish, upload `index.html` to GitHub Pages, Netlify, or another static hosting provider.

## Personalize before publishing
Search in `index.html` for:
- `YOUR_EMAIL@example.com` — replace with your professional email.
- `https://www.linkedin.com/` — replace with your LinkedIn profile URL.
- `https://github.com/` — replace with your GitHub profile URL.
- The experience entries — add exact dates, responsibilities, and project details.
- The IEEE INDICON 2025 entry — add the exact paper title, DOI/IEEE Xplore URL, and final publication status.

The site is responsive and uses plain HTML, CSS, and JavaScript. No build tools or dependencies are required.
